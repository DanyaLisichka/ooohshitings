# Инструкция: как собирать парсеры банков с помощью ИИ (если ты не шизанутый дебил)

Для разработки парсеров можно использовать DeepSeek, ChatGPT и другие ИИ. Главное — предоставить модели реальные данные о том, откуда банк получает курсы валют. **Не стоит просить ИИ написать парсер только по ссылке на сайт:** он может придумать несуществующий API или неверно определить HTML-элементы.

## 1. Найдите источник курсов валют

Откройте официальный сайт банка и найдите страницу с курсами валют.

Далее откройте инструменты разработчика браузера:

* Chrome: `F12` или `Ctrl + Shift + I`.
* Safari на Mac: включите меню «Разработка» в настройках и откройте веб-инспектор.

Перейдите в **Network → Fetch/XHR** и обновите страницу.

Найдите запрос, в ответе которого содержатся курсы покупки и продажи. Откройте его и сохраните:

1. **Request URL** — адрес запроса.
2. **Request Method** — обычно `GET`, иногда `POST`.
3. **Query String Parameters** или тело запроса, если оно есть.
4. **Response / Preview** — ответ сервера с курсами валют.

Если подходящего API нет, скопируйте HTML таблицы с курсами через `Copy → Copy outerHTML`.

Не передавайте ИИ значения `Authorization`, `Cookie`, Bearer-токены и другие секретные данные.

## 2. Какие данные предоставить ИИ

Для качественного результата подготовьте:

* Название банка и ссылку на страницу с курсами.
* URL запроса, HTTP-метод и необходимые параметры.
* Пример ответа сервера в JSON либо HTML таблицу.
* Список нужных валют: например, USD, EUR, CNY.
* Уточнение, какие курсы нужны: наличные или безналичные, конкретный офис или регион, если банк их различает.
* Интерфейс парсера и требования к архитектуре проекта.

Чем больше реальных данных, тем меньше вероятность, что ИИ напишет парсер наугад.

## 3. Что должен соблюдать наш парсер

В проекте используется единый интерфейс:

```php
namespace App\Parser;

interface ParserInterface
{
    public function parse(): array;
}
```

Парсер должен возвращать одинаковый формат данных независимо от банка:

```php
[
    [
        'currency' => 'USD',
        'buy' => 81.20,
        'sell' => 87.60,
    ],
    [
        'currency' => 'EUR',
        'buy' => 91.50,
        'sell' => 99.90,
    ],
];
```

Основные требования:

* Класс находится в `src/Parser/` и использует `namespace App\Parser`.
* Класс реализует `ParserInterface`.
* Парсер создаётся через `ParserFactory` без обязательных аргументов конструктора.
* HTTP-запросы выполняются через Guzzle, а HTML при необходимости разбирается через Symfony DomCrawler.
* Учитываются HTTP-ошибки, невалидный JSON, отсутствие курсов и изменение структуры сайта.
* Используются корректные заголовки и разумные тайм-ауты и задержки.
* Нельзя отключать проверку SSL ради исправления ошибок.
* Парсер не должен выдавать тестовые данные за реальные курсы.

Если используется новый пакет Composer, нужно сообщить об этом и указать команду установки.

## 4. Готовый промпт для ИИ 

Скопируйте шаблон и заполните данные своего банка:

> Разработай PHP-парсер курсов валют для моего учебного проекта — агрегатора курсов 15 российских банков.
>
> Архитектура проекта:
>
> * PHP и Composer;
> * Guzzle для HTTP-запросов;
> * Symfony DomCrawler для HTML, если это необходимо;
> * интерфейс `App\Parser\ParserInterface` с методом `parse(): array`;
> * `ParserFactory` создаёт парсер без обязательных аргументов конструктора;
> * PSR-4: namespace `App\` соответствует каталогу `src/`.
>
> Банк: [название банка].
>
> Страница с курсами: [ссылка].
>
> HTTP-метод и Request URL: [вставить].
>
> Параметры запроса: [вставить, если есть].
>
> Пример Response или HTML: [вставить].
>
> Нужные валюты: USD, EUR, CNY.
>
> Источник курсов: [наличные/безналичные, офис или регион].
>
> Результат должен иметь формат:
>
> ```php
> [
>     [
>         'currency' => 'USD',
>         'buy' => 81.20,
>         'sell' => 87.60,
>     ],
> ]
> ```
>
> Сначала проанализируй предоставленные данные. Не придумывай неизвестные URL, поля JSON или CSS-селекторы. Если информации недостаточно, перечисли, чего не хватает, и задай вопросы.
>
> Затем предоставь полный файл `[Bank]Parser.php`, объясни его работу и укажи необходимые зависимости Composer. Добавь обработку сетевых ошибок, HTTP-статусов и некорректного ответа. Не отключай проверку SSL. В конце дай инструкцию по тестированию через `ParserFactory`.

## 5. Как проверить результат

После генерации кода:

1. Поместите файл в `src/Parser/`.
2. Зарегистрируйте полное имя класса в поле `banks.parser_class`, например `App\Parser\SberParser`.
3. Запустите его через `ParserFactory`.
4. Сравните полученные значения с курсами на сайте банка.
5. Проверьте, что `buy` и `sell` не перепутаны, а значения относятся к нужному офису и типу курса.
6. Проверьте поведение при недоступности сайта и отсутствии валют в ответе.

Если парсер не работает, передайте ИИ полный текст ошибки, актуальный ответ сервера и соответствующий код. Не просите его просто «исправить всё» без этих данных. (или попросите тимлида, х**и вы как дурак)

**Главное правило:** ИИ помогает написать код, но правильность курсов подтверждается только проверкой реального ответа банка.
